# 严格模式：把"需要判断的地方"变成填空和检查

> 这份文档解决一个现实问题：**模型能力参差**。强模型读完方法论就能自由发挥；弱模型自由发挥必跑偏。解法不是换提示词碰运气，而是**换工作模式**——把判断尽量变成填空，把自查变成每步的机器关卡。

## 一、两档模式

| | 自由模式（强模型） | 严格模式（中等及以下模型） |
|---|---|---|
| 开工 | 读方法论后自主设计 | 按本文档的关卡表一步一步走，每步有"完成标志" |
| 分镜 | 按 `structure-bible` + `beat-scaffold` 自由组织 | 照 `beat-scaffold` 的位置逐拍填，拍数 ±4，不改动功能位置 |
| 文案 | 自由创作后自查 | 每拍对照写法公式和禁用清单；数字先留 `{X}` 占位 |
| 计算 | 自己设计模型 | 优先套用通用模型："稳定因素 + 随机因素"（固定种子），只改参数——多数统计/心理/博弈题都能套 |
| 出图 | 按规范自己写提示词 | 从 `image-prompts.md` 的清单和统一要求里挑最接近的改 |
| 质检 | 模型自查总览图 | 每步跑完关卡再进下一步；报错先查 `common-mistakes.md` |
| 你的工作 | 确认选题、分镜、出图 | 同左，外加每步看一眼关卡结果 |

**拿不准就用严格模式**：强模型用严格模式一样能做好，只是自由度低一点；弱模型用自由模式容易跑偏。

## 二、严格模式的关卡表

每一步：做完 → 核对"完成标志" → 不过不进下一步。

| 步 | 做什么 | 完成标志 |
|---|---|---|
| 1 选题 | 出 3 个候选，按"钩子/故事线/能模拟/反转"各打 1–5 分 | 你选定一个，四项都不低于 4 分 |
| 2 分镜 | 定视觉世界与强调色语义；照逐拍骨架写满分镜表 | 你只查三件事：有悬念、反转 ≥ 两层、结尾回到开头 |
| 3 出图（可选） | 填出图提示词表（含风格后缀与文件名） | 你出完图按名放入素材目录；拼总览检查风格与留空 |
| 4 核实事实 | 逐条查证，写进事实表，每条附来源 | 没有空占位；你抽查两三条来源属实 |
| 5 计算 | 写模拟/统计函数（固定种子），算出全部 `{X}` | 数字打印出来合理（无满分卡顶、负数人数等怪值） |
| 6 字幕稿 | 逐拍填字幕（≤20 字），占位符换成第 5 步的值；节奏参数就位 | 时长落在目标区间；禁用清单零命中 |
| 7 画面 | 按分镜实现；每做完两三站 `--sheet` 看图 | 无文字出界/压字幕/两物同动；示意已标注 |
| 8 渲染交付 | 全片渲染 + 封面；规格自检 | 规格正确、无多余音轨；`quality-gate` 终检三遍过 |

## 三、你要亲自把关的四个地方

1. **选题**（最重要）：四项里有一项明显弱，就换题——这一步省下的返工最多。
2. **分镜**：只看三件事——有没有悬念、有没有两层以上反转、结尾有没有回到开头。
3. **事实**：抽查事实表两三条来源，点开确认原文真的这么写。**较弱的模型最容易在这里编造引语和年份。**
4. **总览图**：看图的截帧总览**你自己**过一遍，比让模型自检可靠。

## 四、能力不够时的降级方案

- **写不出好文案**：让它只写"每拍一行说明"（这拍干什么、给谁看），你来改写，再让它照着回填。
- **画面代码总报错**：只改参数和文字，不动结构；骨架和模板本身是能跑的，改坏了就 `git diff` 回退。
- **模拟写不出来**：套"稳定因素 + 随机因素"的通用模型（固定种子 + 逐次累积统计），运气、考试、业绩、比赛类题目基本都能覆盖。
- **实在不行**：换题——选一个和标准骨架结构最接近的题（一个真实的争论 + 一个能用电脑重跑的游戏或实验）。

## 五、诚实条款

工作模式保证的是**流程、准确性和画面质量的下限**；选题和叙事是否打动人，仍然取决于你在第 1、2 步的判断。流量受平台推荐、发布时间、账号状态等很多因素影响，任何流程都不承诺结果。

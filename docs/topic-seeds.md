# 选题种子库：方向、检验与自建题库

> 选题公式：**一个硬核概念 × 一个"你"的处境**，标题必须是在问观众。本文档给的是**找题的方向和检验标准**，附带一批可直接核实的种子题；具体事实在动笔前必须逐条查证并记入事实表（`structure-bible.md` §1 的四项打分先行）。

## 一、五个最容易出好题的方向

1. **被推翻或修正的经典实验/结论**——反转是现成的：观众以为的版本是流行的误传，真实结论更微妙。做之前核实"修正后的版本"本身可靠。
2. **"你每天都在经历，但不知道它有名字"的统计现象**——回归均值、幸存者偏差、基础比率谬误、友谊悖论之类。钩子天然成立：对号入座只需一句话。
3. **一场真实的历史比赛/实验/事件，可以用代码重跑一遍**——"能模拟"这一项最难满足，但满足了的题最省心：模型贯穿全片，数字全部真算。
4. **大奖背后的小故事**——诺奖级结论 + 一个日常应用。权威背书解决可信度，日常应用解决钩子。
5. **你自己评论区的问题**——每期发布后观众反复问的"那为什么……"，就是下一期。

## 二、种子题示例（动笔前逐条核实事实）

> 表中数字为常见文献引用值，**仍需在制作前查证原始出处**；标注 ⚠️ 的题目存在常见误传，做的时候要把误传本身讲清楚（这往往是最好的反转）。

| 题目方向 | 核心概念 | 画面构想 | 核实要点 |
|---|---|---|---|
| 每天进步 1%，一年后你会变成多少？ | 指数与复利 | 两条曲线 1.01ⁿ 与 0.99ⁿ 从同一点岔开 | 1.01³⁶⁵ ≈ 37.8，0.99³⁶⁵ ≈ 0.026；别引申成"每天努力一小时"的鸡汤计算 |
| 体检结果阳性，你真的得病了吗？ | 贝叶斯 / 基础比率 | 1000 个小人方阵逐步筛出真/假阳性 | 自设合理参数（患病率、灵敏度、假阳性率）并在画面标注"示意参数" |
| 一间 23 人的教室，为什么几乎必然有人同一天生日？ | 生日悖论 | 365 个格子扔球，概率曲线在 23 处过半 | 23 人 ≈ 50.7%；默认世界即可当场真算 |
| 为什么你排的队总是最慢？ | 概率与选择 | 三条队伍同时前进 | 三队时"别的队更快"概率 2/3；注意"你的队平均更慢"是幸存者感知，措辞要准 |
| 为什么你觉得朋友总比你受欢迎？ | 友谊悖论 | 社交网络图，高亮"朋友平均朋友数" | Feld 1991；结论是统计性的，不是每个人都如此 |
| 一张纸对折 42 次，能摸到月亮吗？ | 指数增长 | 对数刻度上一路越过珠峰、卫星、月球 | 2⁴² × 0.1mm ≈ 44 万公里 > 地月距离约 38.4 万公里；标"理想化假设" |
| AI 真的懂你在说什么吗？ | 中文房间思想实验 | 一个人在房间里按规则手册查表回复 | 塞尔 1980；思想实验，标"思想实验"，两方立场都给 |
| 换掉所有零件，它还是原来的那条船吗？ | 忒修斯之船 | 木板逐块替换动画 | ⚠️ 别引用"人体细胞 7 年全换一遍"（谣言，多数神经元终生不换） |
| 越得不到越想要？ | 间歇强化 | 固定奖励 vs 随机奖励的两组曲线 | 行为主义经典结论；落点克制，不做心理建议 |
| 一段体验，你只记得结尾 | 峰终定律 | 体验曲线与记忆曲线并排 | 经典实验结论；落点是"设计结尾"，不说教 |

## 三、候选题的四关检验（写成一行记进自己的题库表）

| 关 | 不通过的信号 |
|---|---|
| 钩子 | 标题改不成"为什么你……""你……吗？" |
| 故事线 | 找不到具体年份、人物、论文，只能讲道理 |
| 能模拟 | 画面只能放图片和文字，没有一个会动会变的模型 |
| 反转 | 观众听完只会说"哦"，不会说"啊？" |

四关都过才进制作；差一项强，宁可换题。

## 四、避开

- 热门知识号已做烂的题材（用平台搜索确认，同一概念 30 天内有高赞视频就换角度或换题）。
- 只讲知识、和观众处境无关的题。
- 事实有争议、又无法在片子里讲清争议的题（除非"争议本身"就是反转点，且双方案例都可靠）。

## 五、维护你自己的题库

在上面建一张表（建议 `topics.md`，不进仓库）：列 = 标题方向 / 四项打分 / 模拟方案 / 反转层级 / 事实把握。每期做完回填"实际完播率"，五期后按 `publish-guide.md` §四 定方向。

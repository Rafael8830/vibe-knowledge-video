# 常见错误对照表

> 按"症状 → 原因 → 怎么修"查。覆盖七步流程中最常踩的坑。修完跑 `qa_check.py` 确认。

## 渲染与预览

| 症状 | 原因 | 怎么修 |
|---|---|---|
| 前几帧字体不对（回退默认字体） | 字体没等加载完，或画面里出现的字符没被预加载 | 保留 `document.fonts.ready` 等待；把全片用到的字符先画进隐藏元素触发加载 |
| 同一帧渲两遍结果不一样 | 用了 `Math.random()` / `Date.now()`，或有帧间状态 | 全部换成固定种子发生器；按 `hash(常数+i)` 取每粒子的随机属性 |
| 页面预览正常、渲染出来乱动 | 渲染器设置了 `__RENDER_MODE__`，页面自己的 rAF 循环还在跑并用墙上时钟改画面 | 页面预览循环检测到 `window.__RENDER_MODE__ === true` 时立即停止 |
| 报错"页面未暴露 window.render(t)" | 函数名写错或作用域不对 | 确认是 `window.render = function(t){…}`，且定义脚本在 canvas 之后执行 |
| 渲染到一半报 JS 错误 | 某个 t 值下除零/越界（如 seg 的 a=b） | 检查所有 `seg(t,a,b)` 区间 a<b；给除法加分母保护 |
| 渲染很慢 | 正常现象（全片逐帧截图） | 自查一律用 `--sheet / --stills / --motion`，不要反复整片渲染 |
| ffprobe 发现音频流 | build_video.sh 没按无音轨方式合成 | 检查合成命令是否只封装视频流；平台 BGM 在发布时添加 |

## 剧本与节奏

| 症状 | 原因 | 怎么修 |
|---|---|---|
| 总时长失控（超 165s 或不足 120s） | 句子太长/太短，或站数没控住 | 长句砍到 ≤20 字；不足就补一层反转而不是注水 |
| 某句字幕读不完 | 停留 < 2.5 秒 | 缩句，或让画面多留 0.5 秒 |
| 全片没有一段安静的时间 | 字幕铺太满 | 挑 2–3 处模拟段删掉字幕，让计数自己跑 |
| 术语裸奔 | 术语第一次出现没有例子打底 | 在术语出现前加一句具体例子；术语后紧跟一句大白话同位语 |
| 金句平澹 | "不是A是B"句式用多了 | 全片只留论点处一到两次，其余改成陈述句 |

## 画面

| 症状 | 原因 | 怎么修 |
|---|---|---|
| 中文显示成方块或缺字 | 字体子集缺字 | 用覆盖全字符集的字体文件，或按页面字符动态生成子集 |
| 主体缩在中间像一条虚线 | 尺寸按"画得下"定的 | 主体占画面宽 60% 以上、最小可辨单元 ≥ 20px，反推布局 |
| 一大片发白发糊 | 实心色块进了辉光层 | 有体积的东西画到底层（不参加辉光）；这段把辉光调低 |
| 文字压到字幕带上 | 画面元素太靠下 | 元素最低点限制在纵向 80% 以上 |
| 小字压在主体上 | 标注随手放 | 拉到主体外用细引线；一镜最多一条 |
| 转场中间有说不清的帧 | 两个状态硬插值 | 换成叫得出名字的动作（钻进去/拼起来），或压到 0.5 秒内 |
| 推近镜头先漂移后猛冲 | 缩放线性插值 | 缩放走对数空间、焦点按 1/s 插值 |
| 关键词变色没生效 | 强调标记和字幕原文不完全一致 | 标记里的词必须是该句中原样连续的文字 |
| 相邻两章长得一模一样 | 同一版式没换内容也没加变化 | 同版式可以，但每章的装置和强调点必须不同 |

## 声音

| 症状 | 原因 | 怎么修 |
|---|---|---|
| 有爆音/削波 | 合成时波形叠超 | 逐段限幅；合成后先画波形图人工检查（你听不到渲染中的声音） |
| BGM 和章节切换对不上 | --sections 的切点和分镜表不一致 | 用分镜表的秒数重写 sections；换织体对齐章节起点 |
| 响度忽大忽小 | 段落增益没归一 | 最后统一响度归一到 -14 LUFS、峰值 -1 dB |

## 事实与数字

| 症状 | 原因 | 怎么修 |
|---|---|---|
| 屏上数字与文案不符 | 先写了文案再拍数字 | 先算后写：数字由代码算出或查证后回填文案 |
| 模拟结果每次不同 | 种子没固定 | 固定种子；模拟载入时算完存表 |
| 出处写不出原文题名 | 只查了中译名 | 回查原始论文/著作的原文题名；查不到就换例子 |
| 示意图没标注 | 忘了 | 画面对应位置加"示意/模拟"小字，列进 quality-gate 终检 |

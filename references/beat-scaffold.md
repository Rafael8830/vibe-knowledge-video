# 逐拍写法骨架：把 130 秒拆成一个个"位置"

> `structure-bible.md` 给了段落级时间轴，本文档把它拆到**每一拍的写作任务**：一个 130 秒的标准片约 40–46 拍，每个位置有固定的功能。它不是硬模板——拍数可以 ±4，但每个功能位置必须有人接。新手按表填，熟手当检查表用。

标记约定：★ = 全片强调位（金句或关键数字，合计 6–8 处，时长自动加长）。

## 一、钩子与片名（0–14 秒，约 4 拍）

| 拍 | 功能 | 写法要点 |
|---|---|---|
| b01 | 处境 | 观众亲身经历过的一个具体时刻，前半句切入，不解释 |
| b02 | 处境转折 | 同一件事的反面结果，或"然后发生了什么" |
| b03 | 疑问 | "是 A（常识答案），还是 B（真相方向）？" |
| b04 ★ | 片名卡 | 标题问句；片名卡上另写两字片名 + 英文术语 + 一句副题 |

## 二、真实故事：埋悬念（14–40 秒，约 9 拍）

| 拍 | 功能 | 写法要点 |
|---|---|---|
| b05 | 时间地点 | "年代，地点。"——常驻年代戳同步出现 |
| b06 | 抛出题目/现象 | 一句话把问题、实验或现象讲清 |
| b07 | 具体情境 | 把题目当场演示一遍，让观众代入 |
| b08 | 关键提问 | 把观众心里的问题问出口（"要不要……？"） |
| b09 | 反直觉的答案 | 当事人或专家给出意外答案（必须查证过） |
| b10 | 人物揭晓 | 名字 + 一个让人信服的身份细节 |
| b11 | 引出争议/波澜 | "很快……"——有人强烈反对，或现象被意外证实 |
| b12 ★ | 悬念金句 | 一句话推翻，**不解释**（解释留给模型段） |
| b13 | 过渡 | "谁对？让数字说话。"——收束故事段，进模型 |

## 三、模型演示：多层反转（40–95 秒，约 15 拍）

这是全片最长的段落，读数/模拟在跑，反转叠在结果上：

| 拍 | 功能 | 写法要点 |
|---|---|---|
| b14 | 设定 | 模型规模与前提（数字来自计算模块） |
| b15–16 | 规则 | 两条：一条公式式规则 + 一条"哪个变、哪个不变" |
| b17 | 第一组结果 | 挑出一组（强调色高亮） |
| b18 | 关键数字 | 只说数字（先写占位符，算出后回填） |
| b19 | 排除外因 | 强调"什么都没做、纯靠规则" |
| b20 | 悬停 | 破折号收尾，留半秒悬念 |
| b21 ★ | 对照数字 | 另一组的数字，只说结果 |
| b22 | 直观化 | 把对比换算成更好懂的计数（如"几乎正好是三分之一"） |
| b23–24 | 机制解释 | 反方向也指一下 + 大白话讲清为什么 |
| b25 ★ | 第一层金句 | 对仗短句，点破第一层 |
| b26 | 第二层反转引子 | 固定句式："更反直觉的是：……" |
| b27 | 反转证据 | 换个条件，数字反转 |
| b28 ★ | 第二层金句 | 一句话点破本质（"关键不是 X，是 Y"） |

## 四、历史纵深：第三层反转（95–110 秒，约 5 拍）

| 拍 | 功能 | 写法要点 |
|---|---|---|
| b29 | 卖关子 | "其实，这件事早就有人想过。" |
| b30 | 年份+文献 | 年份 + 人名 + 出处（文献再现同步出现） |
| b31 | 一半符合直觉 | 先说符合直觉的那一半 |
| b32 ★ | 命名 | "它被叫做：……"——概念正式命名 |
| b33 | 后续影响 | 后人怎么报道/误用/修正（年份 + 媒体或人物） |

## 五、解开悬念（110–125 秒，约 5 拍）

| 拍 | 功能 | 写法要点 |
|---|---|---|
| b34 | 回到开头 | 固定句式："现在，回到 [开头的那个东西]。" |
| b35–37 | 当年的验证 | 当年怎么证明的（查证过的细节），演示怎么做、结果如何（可合并到 2–3 拍） |
| b38 ★ | 揭晓金句 | 两句对仗，解释开头的一切 |

## 六、落到观众与结尾（125–145 秒，约 6 拍）

| 拍 | 功能 | 写法要点 |
|---|---|---|
| b39 | 清单引子 | "所以，下次遇到这几种时刻——" |
| b40–42 | 三条小行动 | "① 场景：建议"格式，冒号前是强调词；最好有一条呼应 b03 |
| b43 | 回到开头画面 | 开头的物件 + 一句重新解读 |
| b44 ★ | 结尾金句 | 替观众开脱或重新解读，呼应 b01–b03；这是片名的回声 |

## 七、写文案的五条硬规矩

1. 每拍 ≤ 20 字，读出来像说话，不像论文。
2. 能用数字就用数字，数字必须先经计算或查证，再回填。
3. 金句的前一拍通常是问句或破折号——先制造停顿，金句才立得住。
4. 不说教：不写"我们应该……""要学会……"，写"下次……时，想想……"。
5. 原话、年份、人名，没查证就不写。

## 八、自查三件事

分镜写完只看三点：**悬念埋在第二节、解在第五节；反转 ≥ 两层（b21/b28/b33 三个位置附近）；末拍回到开头画面并呼应钩子。** 加上强调位不超过 8 处、每个功能位置都有接手，骨架就立住了。

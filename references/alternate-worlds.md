# 扩展视觉世界：一条题材一条皮，一个频道一块牌

> `style-guide.md` 定义了本仓库的默认世界（深蓝黑、五区布局、双语字幕）。但不是所有题材都适合同一张皮：讲行为机制和讲抽象数学，最舒服的视觉语言并不一样。本文档给出**建立第二、三套世界**的设计框架和节奏经验值。这是进阶能力——先把默认世界做熟，再考虑扩展。

## 1. 什么时候需要第二套世界

| 题材特征 | 更合适的视觉世界 |
|---|---|
| 一个心理/行为机制，从动物实验或生活场景讲到"你该怎么办" | **插画寓言世界**：每场一幅扁平场景插画 + 一个有动作的主角 |
| 抽象概念（数学、逻辑、信息），能拆成几个当场演的小实验 | **线稿夜曲世界**（即默认世界）：暗底、大字、带刻度的仪器、光点 |
| 一门学问的编年史（一串年份+人+问题） | **档案世界**：近黑底 + 实物感小道具 + 年代里程表 + 原著再现 |
| 拿不准 | 用默认世界。它对"画"的要求最低、对"想"的要求最高 |

## 2. 设计一套新世界的七项清单

每套世界要一次性定死这七项，全片不破例：

1. **底**：底色/渐变/场景插画的具体规格；是否有星点、尘埃、暗角、颗粒。
2. **色板与颜色语义**：主体色、字幕色、标注灰，加**两三个强调色**——并写下每个强调色的含义（答案/错误/已知……），见 `visual-grammar.md` §4。
3. **字体**：中文字幕用什么字重、大字用什么；西文引文、英文小字、等宽标注各用什么。
4. **常驻元素**：最多两三样，每样都在报数（年代戳/读数/章节标），位置全片恒定。
5. **片名卡仪式**：进片名的固定动法（压暗/闪/留一个点）+ 片名卡版式。**这是频道的"厂牌"**——世界可以换，片名卡、字幕习惯、署名方式保持统一，观众才认得出是你。
6. **转场习惯**：这套世界最常用的两三种衔接（见 `visual-grammar.md` §5）。
7. **声音策略**：现成配乐卡节拍（织体分段对齐章节），或全合成（低频垫 + 章节和弦 + 事件音）。归一响度统一。

### 示例：插画寓言世界的典型设计（供参考的思考路径，不是唯一答案）

- 底：每场一幅扁平场景插画（大色块、柔和渐变、不描边），分远景/角色/前景三层，推拉时三层视差不同；辉光只开一档很小。
- 色：字幕暖白；规则句一种庄严色；该机制的核心概念（如"过度"）固定一个警示色，从第一秒用到最后一秒。
- 字：字幕用粗黑体逐字亮起；片名和卡片仍用衬线。
- 常驻：左上一只仪表（0–150 表盘，过红线标"过度"），下面一行"当前对象：×××"——每个新例子都量一次。
- 角色：一个主角贯穿首尾；人物只画剪影或手。
- 声音：现成配乐，一句字幕 ≈ 两个小节，换站卡在小节线上。

## 3. 节奏经验值（对多条爆款的量化统计结论，按世界微调）

这些数字来自对一批此类视频的逐帧实测，做新世界时拿来当起点的标尺：

| 指标 | 经验值 |
|---|---|
| 每分钟字幕句数 | 叙事快的世界 14–16 句；有大字和英文行的世界 8–10 句 |
| 每句停留 | 3–3.5 秒（快）/ 5–6 秒（慢） |
| 字幕覆盖全片时间 | 58%–74%，其余是片名、转场、纯画面 |
| 完全无字幕的时间占比 | 26%–42% |
| 几乎静止的帧 | 占 30% 上下——是特性不是偷懒，那是观众读和想的时间 |
| 硬切数量 | 全片 0–6 处，且多半是故意的一帧闪亮 |
| 每站时长（编年史类） | 平均 8 秒一站，最短 4 秒（一句话+一个图），最长 17 秒 |

## 4. 世界的自检

- 遮住字幕，光看画面：能看出"这是哪一套世界"的风格一致性吗？
- 拿任何一帧和片名卡并排：像同一条片吗？
- 这套世界的每个新装置，是不是都能用同一套图形语言画出来？（如果每站都在发明新画法，说明图形语言没立住）
- 厂牌三件套（片名卡、字幕习惯、署名）跨片一致吗？

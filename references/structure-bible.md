# 结构圣经：选题、骨架与叙事定律

> 数据反复证明一件事：这类片子的数据差距几乎全部来自**叙事**，而不是画面精度。画面再精致，救不了"和观众无关、没有悬念、中段变罗列"的稿子。本文档管叙事层，`narrative-templates.md` 提供逐段模板，两份配合使用。

## 1. 选题打分：四项全强才做

每个候选选题按四项打分，**任何一项弱就换题**：

| 项 | 自问 |
|---|---|
| 钩子 | 观众是不是正处在这个处境里？（考试、社交、消费、身体、情绪） |
| 故事线 | 有没有真实的年份、人物、论文或事件，能串成一段历程？ |
| 可模拟 | 有没有一个模型能用代码真跑出来，并贯穿全片？ |
| 反转 | 是不是"你以为 A，其实 B"，并且能叠两到三层？ |

只讲知识、与观众生活无关的题不做——画面救不了它。

## 2. 四种骨架

| 骨架 | 走法 | 适合 |
|---|---|---|
| A 历史接力 | 问题 → 片名 → 按年份一站站走（人+文献+当场算的小演示）→ 回到今天的你 | 一个概念的发展史（概率、地图、货币） |
| B 反常现象+模型 | 反常现象/日常场景 → 真实事件 → 概念命名 → 模型逐步演示 → 多层反转 → 分步建议 → 回到开头 | 统计现象、博弈、心理学实验 |
| C 隐喻+重新解读 | 三个日常画面排比 → 概念 → 可数的机制 → 套到身体 → 套到感情 → 重新解读 → 今晚的小行动 | 物理/哲学概念类比人生 |
| D 短谜题（60–90 秒） | 抛出一个具体谜题 → 先让观众猜（选项+倒计时）→ 揭晓数字 → 拆解直觉为什么错 → 推广成规律 → 一句余味 | 有唯一反直觉数值答案的题；适合做轻量快更的间奏期 |

骨架 A 必须有一条**悬着的线**：早点抛出一个错误答案或未解的问题，隔几站再回来解掉。没有这条线，编年体就是流水账。
骨架 B 的逐拍写法见 `beat-scaffold.md`；骨架 D 的关键在"先猜"——让观众真押一个选项，揭晓才有输赢感。

## 3. 标准时间轴（以 130 秒为基准，按时长等比缩放）

| 时间 | 内容 | 硬性要求 |
|---|---|---|
| 0–8s | 钩子 | 第 0 帧就有字幕；反常识断言 / "你以为……其实……" / 让人对号入座，三选一 |
| 8–18s | 片名卡 | 中文片名 + 副题 + 英文行；片名之前观众已经"遇到"过概念 |
| 14–40s | 真实事件/实验 | 年份、地点、人物、文献实物；**埋下悬念**；中间插一次"你猜" |
| 40–95s | 模型演示 | 一个模型从头用到尾，读数实时变化；叠 2–3 层反转 |
| 95–110s | 解开悬念 | "现在，回到开头那道题——" |
| 110–130s | 落到观众 + 回扣 | 分步建议（每步一个动作）或重新解读；回到开头的画面；片名回声收尾；声明+引用卡 |

## 4. 十条叙事定律

1. **片名永远不第一个出。** 先用 6–24 秒演一个具体的小东西，让观众先"遇到"概念，再亮片名。
2. **至少埋一个悬念，30–90 秒后才解开。** 悬念要具体到"一个数或一个答案"，不要是模糊的"为什么"。
3. **反转 2–3 层**，用"更离谱的是""还有一个反直觉的细节"引出；每层反转必须比前层更贴观众自身。
4. **画面上永远有一个在变的读数**：计数器、年份戳、进度、"第 N 轮"。它既是进度条也是证据。
5. **每个结论都有实物佐证**：论文原题+译名、年份、原话引语，片尾列引用。数字一律具体。
6. **中段一定转到"你"**：出现在 40–45% 处，"你猜……""这句话是不是很耳熟？"
7. **一个模型从头用到尾**：同一路网、同一组卡片、同一群点反复出现、持续变化。观众会记住它、期待它。
8. **结尾替观众开脱或重新解读，不说教**："你不是不够好，是策略本来就有上限。"最后一句常是开头那句的变体。
9. **场景不换、字幕推进**：不是一句话配一张新图；同一场景撑 2–5 句，每句只改一处。
10. **每 20–30 秒留一段无字幕的纯画面**（模拟在跑、计数在跳）。这是观众的呼吸口，也是"这是真算的"的证明时间。
11. **密度红线（v2.3）**：每句字幕必须携带一个新信息（事实/数字/转折/动作）；两句话讲同一件事就合并；纯过渡句并入下一句的开头。衡量标准：每秒 ≥ 7.5 字、每分钟 ≥ 18 句——用 `scripts/check_density.py` 对字幕稿体检，不过不进分镜。

## 5. 反转的正确叠法

- 第一层反转给"惊讶"（结果反直觉），第二层给"机制"（为什么会这样），第三层给"照进自己"（你的生活里它一直在发生）。
- 每层反转前先给足铺垫（观众自己得出过一次错误答案），反转才有力。
- 最大的那次揭晓，配全片最强的一次画面强调（闪、静音、定格），一条片只用一次。

## 6. 常驻读数设计

把全片的核心概念做成一个**仪器**（表盘/进度条/水位），每个新例子出现就拿它量一次，读数跟着变。检验：你的片子能不能说出"左上角那个读数量过了哪五样东西"？说不出，说明核心概念还没被具象化。

## 7. 与六段叙事弧的关系

`narrative-templates.md` 的六段式是**段落模板**，本文档是**叙事纪律**。写分镜表时逐条对照：悬念埋在哪一秒、几层反转各在哪一秒、读数什么时候开始跳、"转到你"在第几秒、回扣用的是开头的哪个画面。答不全就还没写完。

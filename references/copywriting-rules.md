# 字幕稿规范：写给人读，不是写给人听

> 这类片子没有旁白，观众是在**读**一条片子。字幕稿不是口播稿删掉语气词——它是另一种文体：每句话要配得上一个屏上动作，还要短到一眼读完、眼睛还留有余力看画面。本文档和 `visualization-design.md` 配套使用：那边管画面怎么演，这边管句子怎么写。

## 1. 量：先定数字再动笔

| 项 | 建议值 | 说明 |
|---|---|---|
| 每分钟句数 | 18–24 句（2.5–4 秒/句） | 与风格 DNA 实测一致 |
| 句长上限 | 中文 ≤ 20 字；一行放不下就拆两句 | 拆开的每句各给一个屏上动作 |
| **信息密度** | **每句必须含一个新信息；体裁阈值用 `scripts/check_density.py` 体检** | 新信息 = 新事实/数字/转折/动作，四者有其一。纯过渡、纯氛围的句子**必须删掉或并进下一句**。体裁阈值（来自参考片实测）：电影感稀疏字幕 ≥2.6 字/秒、11 句/分；高密度解说 ≥7 字/秒、20 句/分。密度低是差评第一名 |
| 无字幕时间占比 | 25%–40% | 标题卡、转场、模拟自己跑的段落。写稿时就把这些段落留出来，不要让字幕铺满全片 |
| 英文对照行 | 每句都有（风格 DNA 要求） | 短于中文，意译即可，不逐词直译 |

## 2. 句式工具箱

下面每种句式在爆款片里反复出现。不必凑齐，但钩子句、论点句、末句应该从这里挑：

1. **前半句给直觉，后半句翻过来。**"摸一次，全凭手气；摸上一万次，比例就露馅了。"
2. **破折号后面才放答案。** 术语和数字放在破折号之后，画面在那一刻揭晓："这就是——大数定律。"
3. **定时提问。** 每四到六句安排一个问句，问完的下一句画面就去回答它。提问句本身不配新画面。
4. **一句话写一个人。** 不写生平履历，只写一个让他像活人的细节："嗜赌的医生，第一个认真去'数'运气。"
5. **"不是 A，是 B"只留给论点。** 全片一到两次，用在规则卡或末句。用多了就廉价。
6. **直接对观众说"你"。** 钩子末尾一次，结尾一到两次："你的手机里，也有一颗。"
7. **数字精确到能上屏。**"很多次""差不多"一律回去查出那个数：25,550 次、36.8%、第 5 位。数字是这种片子的节奏锚点。
8. **末句是片名的回声。** 片名《运气的形状》→ 末句"运气，从此有了形状"。写片名时就把末句一起想好。
9. **金句前先造停顿。** 金句的前一拍用问句或破折号收尾，留半秒空——停顿是金句的聚光灯。

## 3. 禁用清单

出现即删：寒暄与预告（"今天我们来聊聊""让我们一起看看"）、总结腔（"这告诉我们""综上所述"）、"众所周知""值得一提的是"、形容词堆叠（"神奇的""惊人的"连用）、任何口头禅。全片句子是陈述句，主语是具体的人和物。

## 4. 用词纪律：一个比喻就是一套词汇表

定下全片核心比喻（见 `visualization-design.md` 第 7 节）后，把它当词汇表用：

- 每个新概念尽量用比喻里的词造句，不引入第二套说法。
- 同一个东西从头到尾同一个叫法。不要一会儿"卡片"、一会儿"选项"、一会儿"候选人"。
- 术语第一次出现时，必须已经有一两个例子打底，且紧跟一句大白话的同位语。

## 5. 强调与染色的克制规则

- 一句字幕**最多**强调一处（「」框出、变色或变色+微放大）。
- 连续三句里至少两句是素色。满屏强调等于没有强调。
- 强调给"答案、术语、关键数字"；错误、危险、超出的内容用另一套色（见全片色彩含义表），并全片不破例。

## 6. 事实与出处

- 每一站至少一个可核对的锚：年份、人名、地名、著作或论文题名、数字。
- 屏上给出处的格式：论文写"作者, 年份"；著作给原文题名 + 中文译名；实验给"年份 + 样本量"。
- 示意的地方标"示意"；假说标"一种假说"；传闻写"据说"。这些小字放画面上，不占字幕。
- 拿不准的事实，宁可整段换例子，不要含糊措辞混过去。

## 7. 定稿交验格式

字幕稿交给分镜之前，整理成一行一句的表（这张表就是分镜表的前两列）：

```
# 起-止(s)   字幕（【词】=强调，#!词=警示色）        所属段落
0.5-3.5      一间 23 人的教室里，                    钩子
3.7-7.0      很可能有两人生日相同。                  钩子
7.2-11.0     这需要多少人才成立？                    钩子（提问，不配画面）
—            （标题卡，无字幕 11-18）
18.5-22.0    把一年想成 365 个格子。                 机制模拟 · 第一站
…
```

定稿前自查：只读字幕（遮住画面）是一篇通顺的短文吗？每一句里的名词，分镜表里都找得到对应的屏上东西吗？把句子按 2.5 秒一行的节奏通读一遍，有没有哪句读不完？

## 8. 标题、副题与发布文案

- **片名**：2–5 个字，是概念本身或一个意象，不用完整句子。
- **副题**：一句大白话，说清看完能得到什么。
- **外文行**：一句英文斜体，气质担当。
- **发布标题**：`Vibe知识大赏 | 《片名》一句钩子？`；发布正文用片子前 30 秒的字幕连成一段话，从钩子讲到第一个结论为止，不剧透后半。

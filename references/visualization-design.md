# 讲解设计：让画面开口讲课

> 本文档解决一个比"好看"更根本的问题：**怎么让观众看懂**。风格 DNA（`style-guide.md`）决定皮相，本文档决定骨架——如果观众看完说不出"因为……所以……"，那么配色再准、动效再顺，这条片子也只是幻灯片。

## 1. 配图与讲解的分界线

先做一个残酷的自测：**把你某一镜的画面，放到另一条题材完全不同的片子里——还能用吗？**

- 能用 → 这是配图。它只负责"这段有东西在动"，不负责传递信息。
- 不能用 → 这才是讲解。它的每一个元素都被这句文案锁死了。

典型的配图长这样：粒子流、抽象网格、随机波形、辉光连线。它们放哪条片子都成立，观众看完只记得"挺炫的"，说不出任何内容。

典型的讲解长这样：字幕说"利息按年滚入本金"，画面就是一摞硬币，每年年底旁边一小堆硬币整个滑进大堆里，大堆的数字跳一格。硬币是具体的，动作是文案里那个动词本身。

**写作铁律：先给每个概念找到形象，再写句子。画不出来的句子，改句子，而不是硬配一个抽象动画。**

## 2. 从概念到形象：六级提问

拿到概念清单后，对每一个概念按顺序自问，前一级有答案就停：

1. **它本身是一个看得见的东西吗？**（骰子、红绿灯、蜗牛、银行卡）→ 直接画它本身，用这条片自己的画风，但必须一眼认得出。
2. **它是一个过程或方法吗？**（二分查找、自然选择、复利）→ 找一个规模小到每步都能画出来的具体题目，现场从头跑到尾。
3. **它是一个数量或程度吗？**（概率、拥挤度、信任）→ 发明一把全片通用的"尺子"（表盘/进度条/水位线），用它量三样不同的东西，观众学会一次，后面自己会比。
4. **它是观众脑子里的感受吗？**（直觉、错觉、上头）→ 设计一个五秒钟的小互动，让这个感受当场发生在观众身上（先出现画面，字幕晚半拍说破）。
5. **它是一条规律吗？**（越多越……、A 越大 B 越……）→ 先画两三个具体例子，再把它们收进同一张坐标系，坐标轴用大白话命名。
6. **都不是**（判断、态度、总结）→ 不画。停住上一幕，或者只上字。

## 3. 形象加固三问

找到候选形象后，再补三问，把它从"能用"升级到"记得住"：

- **观众上礼拜在哪见过它？** 每个难概念拴一件日常小事（等红灯、抢红包、删聊天记录）。找不到生活锚的概念，观众记不住。
- **拉近或拉远一级，它变成什么？** 原因和结果常常隔着一个尺度（一枚硬币的落地 → 一万次投掷的柱状图）。
- **它坏了会怎样？** 正常运转的东西是隐形的，让它错一次，观众才看得见它在干活。

## 4. 每一镜的三道自检

分镜表里每一行都要过，答不出就重做：

| 自检 | 合格答案长什么样 | 不合格答案 |
|---|---|---|
| 屏上这是什么？ | 一个日常的词："一摞硬币""一格日历" | "一些点""一个抽象图形" |
| 它在干什么？ | 一个动词，且就是字幕里那个动词 | "在展示""在流动" |
| 观众因此明白了什么？ | 一句能与上一镜区分开的话 | "感受到了氛围" |

加分检定：把字幕遮住、把角标遮住，只看画面，三道题还答得出来吗？答不出来，说明画面在依赖文字补课——要么画面里加信息，要么承认它是配图并删掉。

## 5. 六种呈现动作

每句字幕在分镜表里必须标注用哪一种（或"停住"）。全片就在这六种里轮换：

1. **让观众动手**：画面摆一个现象，观众先自己起反应（心里补全、产生预期），字幕晚半拍说出他刚想的事。适合开场和一切"你以为……"的位置。
2. **照句子演**：句子里出现的名词，画面里就有那个东西；句子里的动词，画面里真的发生。画面不比句子多说一个字。适合叙事、举例。
3. **小题现场跑**：拿一个最小的具体算例，把方法一步步执行完，屏上挂着状态和计数，数字是真算出来的。适合讲机制、"为什么一定是这样"。跑的过程字幕可以闭嘴，让过程自己说话。
4. **同版式对照**：两样东西放进完全相同的版式，只留一处不同，观众一眼看出"区别就在这"。适合一切"甲比乙"。
5. **收进一张图**：把前面出过场的东西摆进一张坐标图，轴用大白话命名，重点落在图上的一块区域。一条片用两三次，只用来回答"为什么会这样"，且必须排在例子之后。
6. **停住亮字**：规则卡、引文卡、命名大字，或者什么都不加，把上一幕定住。这是"不画"的合法形式。

另外两个贯穿动作：**回场**（前面的道具、尺子在后面再出现一次，接住新结论）和**合体**（把片子的核心比喻和观众的生活物件放进同一画面）。

## 6. 哪些句子不配新画面

大约**每五句里有一句**应该停住或只上字。判断依据是这句话在做什么：

| 这句话在干什么 | 处理 |
|---|---|
| 讲一件事、举一个例 | 照句子演 |
| 讲方法、机制 | 小题现场跑 |
| 描述观众的直觉/错觉 | 让观众动手 |
| 比较两个东西 | 同版式对照 |
| 报一个数量 | 让它可数：一格一格、一颗一颗，或上那把全片通用的尺子 |
| 总结"为什么会这样" | 收进一张图（用前面出现过的东西摆） |
| 把道理落到观众身上 | 合体 |
| 提问 | 停住上一幕，或只留一个问号 |
| 命名、下定义 | 停住亮字，前面的道具可以围拢过来 |
| 引用原话 | 引文卡：原文 + 译文 + 出处 |
| 交代年份人物 | 一行小字贴在已有画面上，不为此换场 |
| 过渡句 | 不画，让下一幕自己进场 |

常见错误：刚演完的结论句再画一张图表（等于不相信观众刚看懂）；没有实指的议论句硬配图（配出来必然是抽象图形）；一个数字能说清的事画了一整张图。

## 7. 一个比喻用到底

全片只定**一个**核心比喻，它必须是开场就能画出来的一个具体东西。之后每个新概念都尽量用它来说：奶茶是它、短视频是它、解法也叫"把它挪出去"。观众即使记不住术语，也能用这个比喻复述整条片。

换比喻的成本极高：观众刚建好的心智模型全部作废。除非结构性的章节切换，不要中途换。

## 8. 分镜表格式

在 `storyboard.md` 里一句字幕一行，七列：

```
| # 时间 | 字幕（强调词标注） | 呈现动作（六种之一/停住/回场/合体） | 屏上是什么，在干什么 | 屏上的小字（标注/数字/出处） | 观众明白了什么 | 声音 |
```

- 表前写清：一句话论点；全片的核心形象；那把"尺子"；哪些镜头是同一画面的复用；每种强调色的含义。
- 表后写清：屏上每一个数是怎么来的；哪些是示意。
- 自查：遮住"字幕"列只读"屏上是什么，在干什么"，看得出在讲什么吗？"停住/亮字"类占比接近五分之一吗？有没有哪一镜换给别的文案也成立？核心比喻出现在至少三站了吗？

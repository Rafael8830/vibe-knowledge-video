# 出图提示词规范（可选环节）

> 底图是**可选**的：默认世界自带的代码背景已经够做完一条片。出图只用来加强开场、历史场景和结尾。本文档管"怎么让 AI 出的图和代码画面融为一体"。

## 1. 风格后缀：每条提示词都要接

出图提示词 = 场景描述 + **风格后缀**。风格后缀是一次性写好、全片复用的一段"统一要求"，内容包含六件事：

1. **题材氛围**：如"暗调电影感纪录片插画""扁平插画绘本风"（与所选视觉世界一致，见 `alternate-worlds.md`）。
2. **色板**：主光颜色、主色两三种、质感（胶片颗粒/纸张纹理）。
3. **负面清单**：画面中**不要出现任何文字、数字、字母、标志、旗帜、徽章**——AI 生成的文字几乎必错，所有文字由代码排版。
4. **人物限制**：只出现剪影或背影，不露真人的脸。
5. **留空要求**：画面下方四分之一和中央偏暗、偏空——那里后期要叠字幕和图表。
6. **画幅**：16:9 横版。

## 2. 六条规则

1. **一张图对应一个场景**：写清时代、地点、光源、主要物件，以及哪一块要留空（"桌面中央留出干净的光斑区域，后期在上面画图表"）。
2. **不画文字**：论文、书、报纸只出空白纸张或纸面纹理，标题、印章、数据全部代码排版。
3. **不画脸**：历史人物用剪影、背影，或者干脆只画他的房间和物件。
4. **首尾呼应**：开头和结尾用同一个场景的**不同时刻**（深夜书桌 ↔ 清晨书桌），提示词里写明"与第 1 张同一张书桌"——观众会感到"回到了开头"。
5. **封面另出两张**：3:4 与 4:3 各一，主体放下半部分，上半留大片干净的深色空间放标题。
6. **文件名先定后画**：提示词表里写死文件名，出完图按名字放入该期素材目录，代码引用不出错。

## 3. 一期的典型出图清单

| 用途 | 数量 |
|---|---|
| 开场场景（与观众处境相关：书桌、手机、教室……） | 1 |
| 历史场景（年代、地点） | 2–3 |
| 空白旧纸（排文献标题用） | 1 |
| 结尾场景（开场场景的另一时刻） | 1 |
| 封面底图 3:4 / 4:3 | 各 1 |
| 透明底小道具（可选） | 按需 |

## 4. 风格不一致时

拿**第一张满意的图**作为参考图上传，后续提示词加一句"与参考图风格一致"。先出 1 张、确认满意，再批量出剩下的——比一次出 6 张再返工省得多。

## 5. 到货检查

图到位后先拼一张总览：风格是否统一（同色温、同质感）、每张的留空区是否真的留了、有没有偷偷长出文字。有问题先重出，再进代码环节。

# 画面语法速查：常见句型怎么演、转场怎么接、动效什么手感

> 前置阅读：`visualization-design.md`（为什么这样演）。本文档是**定了画法之后**的施工速查——分镜表里写不出"屏上动作"时来这里找同型；写转场和动效规格时照这里的清单。

## 1. 句型 → 演法对照表

分镜时逐句自问"这句话在说哪一类"，对号入座。每个演法都遵守一条总纲：**字幕说什么，屏上就发生什么，而且是真的发生**。

| 这句话在说 | 这样演 |
|---|---|
| 一个数量、一个比分 | 让它"长出来"并且数得清：进度条逐格亮、数字从 0 滚到位、一个东西被当场切成几份 |
| 甲比乙 | 左右两栏放进完全相同的版式，只留一处不同，最后各盖一个结论章 |
| 个别没规律、合起来有规律 | 粒子模拟：成百上千个独立的小东西各自随机落下，堆出一个形状 |
| 越来越接近 | 一条实时折线 + 一条目标虚线 + 一个在跳的计数 |
| 有多少种可能 | 画成一棵树或一张格子表，按结果上色，在叶子/格子上数 |
| 一个方法、一个过程 | 现场跑一遍：每步一问一答，角上挂状态（第 N 步 / 还剩 N 种） |
| 一个公式、一个定义 | 先有例子，公式最后出；每个符号都对得上屏上刚出现过的东西，旁边跟一行人话 |
| 谁包含谁 | 套圈图：小圈画在大圈里，落一个点标出例外 |
| 悖论、停不下来 | 一个光点在两个字之间来回弹，越弹越快；或一个转不完的环 |
| 一句名言 | 引文卡自当主体：原文斜体 + 中文大字 + 出处，背后垫一幅与说话人相关的淡图 |
| 某年某人 | 不画脸。常驻的年代戳 + 一件那个时代的东西；人只以剪影出现 |
| 从这里到那里 | 一幅轮廓图，两个点，一样东西沿虚线飞过去 |
| 给概念命名 | 大字 + 辉光，前面出现过的道具围拢过来 |
| 一条规则 | 印成一张卡片，郑重其事（编号、图标、中英对照） |
| 为什么会这样 | 坐标图收拢全片例子，轴用大白话，重点标出一块区域 |
| 这就像那个（比喻落地） | 让比喻的两端出现在同一个画面里 |
| 该怎么做 | 顶上一排步骤标签逐个点亮，每步一个具体动作，不劝告 |
| 语言文字类的例子 | 让字自己演：逐字打出、留空、候选字滚动、字序打乱、盖住一半、划掉重写 |
| 噪声、干扰 | 一条抖动的波形，同时整个画面真的蒙上噪点 |
| 很远、很大、很久 | 一条线两个端点，光点一格格往回传，旁边标数 |
| 回顾 | 前面每章缩成一个小图标排成一排，逐个点亮，一个配一句 |

找不到同型？多半是这句话本身不能数、不能比、不能演——回去按 `copywriting-rules.md` 改句子。

## 2. 一屏一件事：分区纪律

每一刻屏上只有一样东西是亮的、在动的；其余的降到三成以下亮度或离场。以 1920×1080 计：

- **主体区**：纵向约 12%–78%。主体居中，或"图在左、结论在右"。
- **注释带**：y≈70% 附近的小字，一镜最多一条，贴着它解释的东西，需要指向时用细引线。
- **字幕带**：纵向约 82%–95% 只属于字幕（含英文行），任何图形、线头、粒子伸进来都要让开。
- **四角**：常驻元素（水印、年代戳、读数、章节标）的全_package 位置，全片恒定。
- **留黑**：画面三成以上是空的底。不用装饰填空。

## 3. 常驻元素 = 一直在报数的仪器

全片从头挂到尾的常驻东西只有两三样，而且**每样都在报一个数据**：年代戳报"现在讲到哪一年"，读数报"眼前这个东西有多强"，章节标报"讲到第几部分"。

高阶用法：把全片的核心概念做成一个**仪表**，每个新例子出现就拿它量一次（读数跟着变）。观众学会一次，之后会自己拿它去比。设计自检：你的片子左上角那件常驻物，量过几样东西？只有一件，它就只是装饰。

## 4. 颜色是词汇

定稿前写下一张三行小表并全片执行：**每种颜色只有一个意思，从第一次出现到最后不破例**。例如：金 = 答案/被点亮的；警示红 = 错的/过头的；冰蓝 = 平常/已知的；灰 = 标注。刻度上的点是蓝是金，本身就在说话。与 `style-guide.md` 的配色规范配合使用：那边定"哪些色"，这边定"每个色什么意思"。

## 5. 转场手法清单（不硬切）

镜头之间靠下面这些方式衔接，按需选用；一条片里"闪"不要超过三次：

| 手法 | 做法 | 时长 | 适用 |
|---|---|---|---|
| 溶解 | 旧的淡出、新的淡入，重叠一半 | 0.5–0.7s | 默认 |
| 变形 | 同一个几何体换一种画法 | ~0.55s | 实物 → 线框/图表 |
| 留一个点 | 上一幕的某个点不消失，滑到新位置变成下一幕的东西 | ~0.9s | 章节切换的"引子" |
| 闪 | 整幅提亮再落回，新画面在亮时换进来 | 0.4–0.7s | 片名卡、定理落地（限量） |
| 推近穿过 | 当前画面以一点为中心放大穿过 | ~1.3s | 进入下一个年代/尺度 |
| 压暗 | 场景暗到底，新的光从暗里浮出来 | ~0.55s | 进片名卡 |
| 卡片盖上来 | 一张纸卡从下面升起盖住场景，带一点倾角 | ~0.5s | 规则卡、引文卡 |
| 暗一下 | 整幅暗到近黑再亮起，常驻角标同时换 | ~1s | 章与章之间 |
| 收进胶片带 | 前几个镜头缩成胶片带上的几格，整条带子斜着滚走 | ~1.2s | 系列实验的收束 |
| 回到同一画面 | 结尾重画开场，机位、颜色一样，只改一处 | — | 回扣 |

章内还有省工的一招"**同屏换内容**"：版式不动，只换里面的东西（换角色、换数字）。

## 6. 动效手感六条

1. **字是显影出来的，不是飞进来的。** 逐字由虚变实或逐字亮起，一秒内出完整句；没有弹跳、没有从屏幕外滑入。
2. **线是画出来的。** 曲线、轮廓、连线从一端长到另一端，线头带一个小光点。
3. **数是数上去的。** 结论数字约 0.9 秒从 0 滚到位（先快后慢）；模拟里的计数每帧都在变。
4. **东西有重量。** 落下来的先加速、落地弹两下、越弹越低，脚下有影子；盖章是砸下来加一下震动。
5. **永远有一点点在动。** 尘埃在漂、星点在闪、辉光在呼吸——但主体出完就停住让人读；全片允许约三分之一的帧几乎静止，那是留给观众读字幕的。
6. **强调靠亮度，不靠尺寸。** 重点是变亮、发光、换成强调色；把字幕放大是全片级别的重招，一两条封顶。

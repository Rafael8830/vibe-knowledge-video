# 渲染工程手册：把画面写对、写稳、写快

> 前置：`assets/template.html` 给了可用的骨架；本文档讲骨架背后的**工程纪律和常见装置的写法**。所有条目都服务于一个契约：`window.render(t)` 给定任意秒数画出确定的帧——这是逐帧渲染、只重渲一段、乱序截帧的前提。

## 1. 纯函数与确定性

- **每一帧只由 t 决定**：不用计时器、不监听事件、不在帧间保存任何状态（没有"上一帧的位置"）。
- **随机数只用带种子的发生器**：页面载入时构造 `mulberry32(seed)` 一类的发生器；粒子 i 的所有随机属性（落点、延迟、抖动相位）由 `hash(固定常数 + i)` 得出。**禁止 `Math.random()` 和 `Date.now()`**——它们让"同一帧渲两遍"结果不同，QA 的确定性检查会失败。
- **运动全是时间函数**：一个量从 a 到 b，写 `k = ease(seg(t, t0, t1)); v = lerp(a, b, k)`。出现–停留–消失的包络写一个通用 `fade(t, a, b, fin, fout)`，每个场景乘自己的包络，**不要**用 `if (t < 17) A(); else B();` 硬切——让两场的时间窗重叠半秒、各自乘淡入淡出。

## 2. 模拟要真算，但要能回放

- **载入时把整场模拟一次算完，存成表；每帧只按 t 查表。** 例如"掷一万次"：载入时用固定种子循环一万次，把每次之后的比例存进数组；渲染时 `n = 次数曲线(t)`，画折线到第 n 个点、计数器显示表[n]。观众看到的是真算的结果，渲染时却不再模拟。
- **次数曲线先慢后快**：`n(t) = 总次数 × easeIn(seg(t, a, b))`，让人先看清头几下，再让计数飞起来。
- **粒子同理由序号决定**：粒子 i 的出发时刻、随机路径都来自 `hash(i)`；某一帧的位置 = `f(t − 出发时刻_i)` 直接算出，**不要一帧一帧积分**。这样任意 seek 都对。

## 3. 辉光管线与"under 层"

常见出帧做法：内容画在一张透明层上，出帧时把该层模糊一两次、用**加法混合**叠回底图——所有亮的东西自动获得辉光。由此有两条铁律：

- **实心的大色块会糊成一团白。** 有体积、有材质的东西（卡片、身体、地图、场景插画）画进**不参加辉光的底层**（底之上、内容之上）；只有发光的线、光点、字画在辉光层。
- 辉光过曝时把强度调低一档，而不是给所有东西描边。

## 4. 镜头推拉：对数空间

跨数量级的推近/拉远，如果线性插值缩放，会先平移、后猛冲。正确做法：

- 缩放在对数空间走：`s = exp(lerp(ln s0, ln s1, k))`；
- 焦点按 `1/s` 插值跟随；
- 自己把世界坐标换算到屏幕坐标，**不要用画布的 scale 变换**——否则线宽和字号会跟着缩放糊掉。

## 5. 结构组织

- **一个场景/一站一个函数**，自己管自己的进出场包络；常驻元素（水印、年代戳、读数、字幕）在最外层统一画，永远最后画字幕。
- **长片按章拆文件**：超过四五百行就在 index.html 里按顺序挂多个 `<script>`，每章往一个命名空间挂自己的函数；主文件只留字幕表、章节表和调度。改一章不碰别的章。
- **每站开头取本地时间** `const lt = t - 站起点`，站内全用 lt——整站挪动时只改一个数，避免时刻散落多处。

## 6. 常见装置写法提示

| 装置 | 要点 |
|---|---|
| 数字滚动 | 值 = 目标 × easeOut(seg(t))，用等宽数字字体；单位小一号放旁边 |
| 逐字显影/打字 | 用逐字布局算好每字位置；第 i 字的透明度 = seg(t, 出现+i×错峰, +时长)；显影用"模糊→清晰"，打字机用"出现+光标" |
| 进度条/量尺 | 底槽用低透明度中性色，填充用强调色；刻度和数字先于填充出现 |
| 年代戳换站 | 逐位滚动（旧数字上移淡出、新数字下移淡入），左边数位先停；地点文字上下交替 |
| 连线标注 | 元素外拉一根细线到小字；一镜最多一条 |
| 图表生长 | 先画轴和刻度（快），再让数据线从左长出（线头带光点），最后落标注 |
| 网格/点阵 | 单元先按序号逐个淡入（用 hash 打乱次序更自然），再让数据点亮 |
| 卡片/纸张 | 底色 + 两三层极淡描边 + 轻微旋转（±1°）+ 投影；内容排版固定模板 |

## 7. 文字

- **Canvas 中文必须手动换行**，禁止依赖自动换行；定稿前用 measure 量最长的字幕句，超宽就缩字号或改文案。
- 渲染器会等 `document.fonts.ready`，但页面里**用到的每个字**最好都让字体预加载（把全片字符画进隐藏元素一次），否则前几帧可能回退字体。
- 字幕逐字动效控制在 1 秒内出完；关键词染色在文本解析层做（标记语法如 `{词}`），不要手写字符下标。

## 8. 性能

- 上千个粒子用单色 `fillRect`，不要每个都开 shadow/blur——辉光交给出帧的统一模糊。
- 慢的预处理（字形采样、模拟计算、点阵生成）全部放载入时，缓存成数组。
- 每帧只清重画变化的部分是过度优化；先保证 `render(t)` 简单正确，卡了再优化热点。

## 9. 自检钩子（可选但推荐）

暴露 `window.selftest()` 返回 `[{name, ok, got, want}, …]`：把关键计算（概率、峰值、比例、边界）写成断言。渲染前跑一遍，数字错了在页面上就看得见，不用等 QA 报警。

# 返工话术与分步推进

> 给两种场景用：① AI 一次做完但成片不对劲，需要**一句话说清哪里不对、要什么**；② 题目大、把握小，想**一轮一轮推进**、每轮看过再往下。两套都是直接可复制的提示词，方括号处填自己的内容。

## 一、分步推进：八轮，每轮有过关标准

**第 1 轮 · 立题与事实表**
```
我想做一条 [时长] 秒、无配音、靠字幕和画面讲的知识短片，题目是 [题目]。
先别写文案。给我：
1. 一句话论点（观众看完能复述的那句）。
2. 一个贯穿全片的比喻：必须是开场就能画出来的一个具体东西。
3. [4-8] 站的清单：每站一个年份/场景、一个人、一个问题、一个能当场演的小实验、一个结论数字。
4. 事实表：每个年份、人名、题名、数字的出处和把握程度，没把握的标出来。
```
过关：论点一口气说得完；比喻画得出来；每站的小实验你能想象出画面。

**第 2 轮 · 字幕稿**
```
按这个清单写字幕稿。观众是"读"片子的，不是听的：
- 每句 ≤ 20 字，一句一件事；全片约 [N] 句；预留 [25-40]% 无字幕时间（片名卡、模拟自己跑的段落）。
- 开头不自我介绍，直接是钩子；钩子末尾要么是问句、要么对"你"说一句。
- 每站 2-3 句：问题、做法、结果，结果里有具体数字。
- "不是……是……"全片最多两次；末句是片名的回声。
- 禁止"今天我们来聊""这告诉我们""众所周知"。
输出成表：序号 / 字幕 / 属于哪一站 / 这句话屏上要发生什么。
```
过关：只读字幕是一篇通顺短文；每行最后一列都填得出来。

**第 3 轮 · 三张样帧定风格**
```
先别做动画。用 index.html + render(t) 给我三张 1920×1080 静帧：钩子、片名卡、一个典型的站。
背景、配色、字体、常驻元素按 style-guide.md；强调色含义：[金=…，红=…，蓝=…]。
三张要看得出是同一条片子。渲染用 --stills 命令。
```
过关：缩到手机大小字幕还清楚；颜色含义与设定一致；画面三成以上留黑。

**第 4 轮 · 分镜表**
```
把字幕稿扩成分镜表，一句一行：起止时间 / 呈现动作（六种之一或"停住"）/
屏上是什么、在干什么 / 屏上的小字（标注、数字、出处）/ 观众明白了什么 / 声音。
"停住/亮字"类约占 1/5；相邻两行不能是同一主体做同一件事；
每 20-30 秒留一段无字幕的纯画面；要真算的装置列出来，写明算法和最终数字。
```
过关：每个模拟的最终数字与事实表一致；遮住字幕列能看懂全片脉络。

**第 5 轮 · 最难的一镜**
```
现在做全片里最难演的那一镜（[描述]），截原尺寸静帧给我。
遮住字幕和小字，要能答出：这是什么 / 它在干什么 / 观众明白了什么。
答不出来就重画，不许往下走。
```
过关：三问答得出；手机缩放后仍可辨认。

**第 6 轮 · 前 30 秒**
```
把钩子 + 片名卡 + 第一站做完，渲出来。转场先逐个 --motion 拼图检查，再渲片段。
字幕出现后 0.3 秒内屏上要有动作；片名是被"引出来"的，不是切过去的。
```
过关：静音看，知道在讲什么；没有硬切。

**第 7 轮 · 铺全片**
```
按分镜表铺完。一站一个函数，常驻元素和字幕在最外层统一画。
每做完两三站跑一次 --sheet 16 拼图自查：有没有东西伸进字幕带、
有没有两样东西同时抢着动、相邻段落是不是长得一样、该回场的东西回来了没有。
```

**第 8 轮 · 声音与终检**
```
BGM 织体分段对齐分镜章节（--sections），响度归一到 -14 LUFS。
最后按 quality-gate.md 终检三遍 + 门槛表逐条过，
把不合格的时间点列出来修完再交。
```

## 二、返工话术：看到什么，怎么说

毛病要**指认到秒、说清要什么**，不要说"感觉不太好"。对照表：

| 看到的毛病 | 这样说 |
|---|---|
| 第一秒就是片名 | 片名往后放。先用十秒演 [那个东西]、问出问题，再亮片名。 |
| 字幕整行弹出或从下面滑上来 | 字幕原地显影：逐字由虚变实，一秒内出完；不要位移、不要弹。 |
| 图是一张静态图表 | 让它真的算：从第 1 次画到第 N 次，计数器跟着跳，最后停在 [这个数]。 |
| 一屏里东西太多 | 一屏只讲一件事：这句只留 [主体]，别的降到三成亮度或先离场。 |
| 颜色越用越多 | 强调色只用 [金/红/蓝]，每种一个意思；把不符合的改掉。 |
| 镜头是硬切的 | 别切。让上一幕的 [那个点/那个形状] 留下来，变成下一幕的 [……]。 |
| 转场花哨（旋转/翻页/故障） | 只用溶解、变形、推近、闪四种；全片闪不超过三次。 |
| 结尾是一段总结 | 不要总结。回到开场画面只改 [一处]，末句用片名的回声。 |
| 看不出讲到哪了 | 左上角挂一个 [年代戳/章节标/读数]，全片恒定，换站时它跟着变。 |
| 屏上没有出处 | 每站角上给：原题名 +《中文名》+ 作者年份；示意图标"示意"。 |
| 节奏一个速度到底 | [某句] 是全片最重的一句：前面留两秒纯画面，这句停三秒再走。 |
| 所有东西都在发光，糊成一片 | 辉光只给光点、细线、大字；卡片和实物不发光，画在不参加辉光的底层。 |
| 字太小 | 手机横屏看：字幕不小于 46px、标注不小于 20px，再小的删掉。 |
| 字幕读着像口播稿 | 删掉"我们""其实""那么"，每句砍到 20 字内；一句话拆成两句、给两个动作。 |
| 人物画成了卡通脸 | 不画脸：用年代戳 + 一件那个时代的东西；非要人出现就用剪影。 |
| 元素进场都弹一下 | 去掉所有弹跳。字是显影、线是画出、数是数上；只有真的落地才弹。 |
| 每章各画各的，像几条片拼的 | 全片只用 [一个光点/一套卡片] 的图形语言，第 [N] 章改用它来演。 |
| 标注压到字幕上了 | 字幕带（纵向 82%–95%）只放字幕，把 [那个元素] 上移。 |
| 配乐和画面各走各的 | 把 [这一站] 的开头对到配乐 [这一拍]，织体分段对齐章节切换点。 |
| 模拟每次渲染结果不一样 | 随机数全部换成固定种子；禁止 Math.random / Date.now。 |
| 数字看着不对 | 把屏上每个数字与事实表逐个对，列出不一致的，先改数据再改文案。 |

## 三、验收的反向话术（交片前问 AI）

```
交片前逐条回答，答不上来的当场修：
1. 静音、遮住字幕看：每一段在讲什么？
2. 只读字幕：哪一句的名词屏上找不到？
3. 钩子的画面在结尾回来了吗？核心比喻出现至少三次了吗？
4. 每个数字都核对过吗？每一站都有出处吗？
5. 有没有哪一秒，两样东西同时在动？
6. 哪些段落你没有逐帧看过？如实列出。
```

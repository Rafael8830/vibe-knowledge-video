# 情绪世界：短情绪命名片的视觉世界

> **版本：** emotion-worlds v1.0 · 适用主版本：vibe-knowledge-video v2.4.0
> **性质：** 增量扩展世界，不是默认世界的替换，也不是对默认世界的修改。
> 默认世界继续做 120–165 秒的硬知识纪录片；本世界只做 13–50 秒的情绪命名短片。
>
> **定位一句话：** 一个情绪，一个名字，一张卡，一句收束。
>
> **先读顺序：** `style-guide.md`（默认 DNA）→ `alternate-worlds.md`（扩展框架）
> → 本文档（情绪世界的具体落地）→ `visualization-design.md`（讲解设计）
> → `quality-gate.md`（质量门）。
>
> **原创性底线（必读）：**
> 五毒、七宗罪、七情这类概念本身属于公共题材，可以讲；
> 但不要复制任何已发布成片的具体文案、卡片排布细节、动物或人物造型。
> 本文档只定结构、字段、版式和节奏，文案和造型每一期都要原创。
> 事实表里写“待核实”的内容，一律不进成片。

## 1. 一眼看懂：默认世界 vs 情绪世界

| 维度 | 默认世界（原有，不动） | 情绪世界（新增） |
|---|---|---|
| 一句话 | 把硬知识拍成电影感纪录片 | 给一个情绪命名，让观众对号入座 |
| 时长 | 120–165 秒 | A 型 13–15 秒；B 型 45–55 秒 |
| 叙事弧 | 钩子 → 历史锚点 → 机制模拟 → 反转 → 现实落点 → 声明引用 | 触发 → 化身 → 信息卡 → 收束（A 型）；引言轮换 → 终卡（B 型） |
| 证据方式 | 论文、年份、人物、真模拟、屏上计数 | 生活触发、象征、化解、对立项、古籍或来源出处 |
| 核心画面 | 文献复原、曲线、网格、地图、卡片矩阵 | 一张信息卡 + 一个情绪身体（动物或剪影） |
| 声音 | 无旁白，76–78 BPM 合成 BGM，段落对齐章节 | 同样以画面文字为主；15 秒版把织体压成三段（见 4.7） |
| 质量门 | 六维评分 + 人工看图两轮 + 数字纪律 | 同一套质量门 + 本文档第 15 节的短片专项检查 |
| 适用题材 | 数学、概率、哲学、模型、实验史 | 情绪、心态、人际反应、公共情绪组 |

> 一句话区分：默认世界回答“这件事为什么是这样”，情绪世界回答“你现在这种感觉叫什么，它长什么样，怎么应对”。

## 2. 什么时候用，什么时候不用

| 情况 | 结论 |
|---|---|
| 讲一个情绪、一种心态、一种人际反应 | ✅ 用本世界 |
| 讲一个定理、模型、历史事件、实验过程 | ❌ 用默认世界 |
| 需要真模拟、真计算、论文引用链 | ❌ 用默认世界 |
| 只有 15 秒左右，想做一集一情绪的合集 | ✅ 用 A 型 |
| 有 50 秒左右，想一集讲清一组情绪 | ✅ 用 B 型 |
| 需要配音旁白、竖屏、实拍素材 | 都不直接适用，需在简报里单独注明改动 |
| 触发只是抽象议论，没有具体小事 | ❌ 先换题，不要硬做 |
| 情绪没有身体（动物、剪影、仪表都立不住） | ❌ 先换形象或换题，不要只贴标签 |

## 3. 两种成片形态

### 3.1 A 型：15 秒情绪单集（单情绪、单集、合集化）

- 时长：13–15 秒。
- 结构：四拍，缺一不可，顺序不能倒。
- 节奏：触发要快，命名要准，收束要停得住。

| 拍 | 时间（15 秒版） | 任务 | 画面任务 | 常见翻车 |
|---|---|---|---|---|
| A1 触发 | 0–5 秒 | 一个日常小事，让观众先说“这就是我” | 一个具体场景 + 一个在变的读数 | 触发写成道理，观众无法代入 |
| A2 化身 | 5–8 秒 | 情绪长出一个身体 | 一个原创动物或剪影入场，它的动作就是下一拍的动词 | 动物只是装饰，动作和文案无关 |
| A3 信息卡 | 8–13 秒 | 给情绪命名并讲清症状与解法 | 左卡右图，卡片字段见第 9 节 | 一张卡塞两个情绪，或字段缺项 |
| A4 收束 | 13–15 秒 | 一句反转或重新解读，替观众开脱或点醒 | 终卡定格，大字停留，不再切新画面 | 收束又切新画面，观众记不住最后一句 |

### 3.2 B 型：50 秒多卡知识集（一组情绪、一集多卡）

- 时长：45–55 秒。
- 结构：引言轮换 + 终卡收束。
- 节奏：每张卡 7–10 秒，一张卡只讲一个情绪，不在一张卡里塞两个名字。

| 段 | 时间（50 秒版） | 任务 | 画面任务 |
|---|---|---|---|
| B1 引言轮换 | 0–35 秒 | 每段先给一句生活引言，再切到对应情绪卡 | 引言句必须是具体场景，不能是抽象议论；每段换色只换主题色，不换版式 |
| B2 终卡 | 35–50 秒 | 选本集最核心的一个情绪做大卡收束 | 大字 + 拉丁或英文名 + 一句定位（例如“之首”“其一”），定格 3 秒以上 |

### 3.3 第三种子卡式：西式命名变体（可选，只在西式命名系列里用）

- 适用：七宗罪这类西式命名组。
- 字段见第 9.3 节。
- 一集只用一种卡式，不要在一集里混用 A 型解法行和 B 型象征行。

## 4. 新世界的七项清单

开一集前必须定死这七项，全片不破例。开工前先把第 12 节的简报填完，用户确认后再写代码。

### 4.1 底

- 底色：深蓝黑，与默认世界一致，`#050510` 到 `#12122a`，可用极淡星点或噪点。
- 画面三成以上留黑，不用装饰填空。
- A 型触发段可以用一个暗色日常场景（室内、手机界面、街道剪影），但场景必须服务于触发句，不能是无关配图。
- B 型以暗底 + 单色霓虹描边为主，场景退后，卡片和剪影向前。

### 4.2 色板与颜色语义

- 主文字：白 `#EAEAF2`；注释与英文小字：灰 `#8A8AA0`。
- 每集只定一个主题色，主题色 = 本集情绪的颜色。
- 主题色全片只有一个意思：它是本集情绪的标记，不是装饰。
例如一集里主题色同时出现在大字、身体描边、仪表指针和收束句的关键词上；
换一集可以换主题色，但同一集里不能中途换义。

开集前填空（不填空不开工）：

```
底：深蓝黑 #050510–#12122a
主字：#EAEAF2
注释：#8A8AA0
本集主题色：______（只写一个色值 + 它代表的情绪）
辅助色（最多一个）：______（只用于解法行或对立项）
```

禁止：每行换一种颜色、满屏强调、主题色和解法色混用。

### 4.3 字体

- 大字：中文粗黑体，A 型终卡大字建议与默认世界标题卡同级的可读性，手机横屏下仍一眼可辨。
- 小字与标注：中文常规或中粗，英文与拉丁名用斜体西文。
- 双语规则：关键名给原文或拉丁名 + 中文，短于中文，意译即可，不逐词直译。
- 古籍出处只写书名，不写成大段引文；出处必须在事实表里核实过，拿不准就换一个能核实的出处或删掉出处行。

### 4.4 常驻元素（最多两三样，每样都在报数或报位置）

- 系列标签：左上或顶部固定位置，例如“系列名 · 其二”，全片位置恒定，换卡时只换数字和情绪名。
- 读数仪表（二选一，全片只用一种）：
- 气压 / 火气仪表：触发段指针上升，命名段指针定格；
- 步骤标签：B 型多卡时，顶部或角落显示“其一 / 其二 / 其三”，让观众知道现在是第几张卡。
- 水印：左上作者署名，全片不动，与默认世界一致。

### 4.5 片名卡仪式（频道的“厂牌”，跨世界保持统一）

- A 型不单独做长片名卡：命名卡本身就是片名卡，大字落下时要有一次明确的“命名时刻”，
之前是触发和化身，之后才是定义和解法，顺序不能倒。
- B 型终卡是片名卡：大字 + 拉丁或英文名 + 一句定位，背景压暗或放射光定格 3 秒以上。
- 跨集保持统一的三件套：系列标签写法、字幕习惯、署名方式。世界可以换，这三件不能每集换。

### 4.6 转场习惯

- 首选：内容长出来的转场。上一幕的一个点、一条线、一件道具留下来，变成下一幕的东西。
- 可用：溶解、变形、留一个点、压暗、卡片盖上来。
- 禁止：黑场淡入淡出、旋转、翻页、故障、粒子爆炸。
- A 型特别注意：触发到化身的转场不能是硬切后凭空换动物，
要让触发场景里的一个元素（例如一个物件、一个气泡、一个仪表指针）变形或滑向化身。
- 全片“闪”不超过三次，只用在命名落地和终卡收束。

动效时长参考（与 `visual-grammar.md` 一致）：

| 手法 | 时长 | 用在哪 |
|---|---|---|
| 溶解 | 0.5–0.7 秒 | 默认衔接 |
| 变形 | 约 0.55 秒 | 实物 → 线框或图表 |
| 留一个点 | 约 0.9 秒 | 章节切换的引子 |
| 闪 | 0.4–0.7 秒 | 命名落地、终卡（限量） |
| 推近穿过 | 约 1.3 秒 | 进入下一个尺度或年代 |
| 压暗 | 约 0.55 秒 | 进片名卡或终卡 |
| 卡片盖上来 | 约 0.5 秒 | 规则卡、引文卡、信息卡 |

动效手感六条照用：字是显影出来的，不是飞进来的；线是画出来的；
数是数上去的；东西有重量；永远有一点点在动；强调靠亮度，不靠尺寸。

### 4.7 声音策略（先定策略，再谈曲风）

- 本世界默认仍是画面文字叙事，声音只做两件事：给节奏打点，给命名和收束留呼吸。
- 如果用现成配乐：织体分段对齐章节，命名卡落在小节线上，收束段回落。
- 如果用合成配乐：沿用 `scripts/synth_bgm.py` 的做法，76–78 BPM、小调、pad + 钢琴柱式和弦 + 轻打击，
但 15 秒版要把段落压成“触发一段、命名一段、收束一段”，不要照搬 130 秒版的六段织体表。
- 重要限制：声音必须以实际成片为准写进交付说明。
没有实听确认的配乐风格、BPM、旁白有无，一律写“未确认”，不许凭感觉补写。

## 5. 版式总图：1920×1080 落位

### 5.1 默认五区（照用，不许改区）

```
┌─────────────────────────────────────────────┐
│ y=40-80 左上: @作者水印 顶中: 系列/其第几 │ ← 全片恒定
│ │
│ y=280-700 中央: 主视觉区 │ ← 卡片 / 化身 / 剪影
│ (占画面 30%-65%) │
│ y≈750 (70%) 画面注释带 │ ← 一镜最多一条小字
│ y≈920-980 (85-91%) 双语字幕带 │ ← 中文主句 + 英文斜体小字
└─────────────────────────────────────────────┘
```

- 字幕带只属于字幕，动物、卡片、仪表、粒子一律不许伸进来。
- 注释带一镜最多一条，贴着它解释的东西，需要指向时用细引线。
- 主体区纵向约 12%–78%，主体居中，或“左卡右图”。

### 5.2 A 型：左卡右图

```
┌──────────────────────────────────────────────┐
│ 系列名 · 其第几 │
│ │
│ ┌──────────────┐ ┌──────────────────┐ │
│ │ 大字：情绪名 │ │ │ │
│ │ 定义：一句话 │ │ 化身（动物/ │ │
│ │ 症状动词 × 2 │ │ 剪影，主题色 │ │
│ │ 解法 + 出处 │ │ 描边） │ │
│ └──────────────┘ └──────────────────┘ │
│ │
│ 底部：收束句（终卡定格，字号最大、停留最久） │
└──────────────────────────────────────────────┘
```

- 卡片与化身左右留白相等，不要一侧贴边、一侧留大空。
- 卡片逐行亮起，不要整卡一次性弹出；每行亮起间隔以能读完为准。

### 5.3 B 型：多卡同版式

- 每张卡版式完全相同，只换内容：大字、拉丁或英文名、定义、象征、化解、底部阐释、右侧剪影。
- 换卡时版式不动，只换里面的东西（同屏换内容），这是省工且保持系列感的做法。
- 换卡的信号只能有一个：主题色变了，或步骤标签变了，或剪影变了，三者至少其一，
不要同时换版式、换底色、换字体，那样会像换了一条片。

## 6. 颜色系统：颜色就是词汇

定稿前写下一张三行小表并全片执行：**每种颜色只有一个意思，从第一次出现到最后不破例。**

| 颜色角色 | 写法 | 举例（开集前填空，不是固定答案） |
|---|---|---|
| 底 | 深蓝黑 | `#050510`–`#12122a` |
| 主字 | 白 | `#EAEAF2` |
| 注释 / 英文小字 | 灰 | `#8A8AA0` |
| 本集主题色 | 一个色值 | 本集情绪的标记色，出现在大字、描边、仪表、收束关键词 |
| 辅助色（最多一个） | 一个色值 | 只用于解法行或对立项 |
| 警示色（如需） | 一个色值 | 只用于“错的 / 过头的”，不用于普通强调 |

主题色分配方法（不要抄任何成片的配色表）：

1. 先按情绪组列出全部情绪名，一组一表。
2. 给每个情绪只配一个主题色，相邻两集的主题色要有可辨识的差别。
3. 把这张表写进简报，整组做完前不改表；改表要整组重审，不能只改一集。

## 7. 身体系统：情绪怎么长出身体

沿用 `visualization-design.md` 的铁律：**先找形象，再写句子。**

### 7.1 身体的三种合法形态

| 形态 | 做法 | 禁忌 |
|---|---|---|
| 原创动物 | 黑色身体 + 主题色描边，动作就是文案动词 | 不要照搬已发布成片的动物造型和配色组合 |
| 黑色剪影 | 人侧脸或全身剪影 + 单色霓虹描边，不画脸 | 不要画真人脸、不要画卡通脸 |
| 日常物件 + 仪表 | 一件日常物件 + 一个在变的仪表（指针、格子、颜色加深） | 仪表不动就是装饰，必须删掉或改成真的在报数 |

### 7.2 动作词汇表（动作必须就是文案动词）

| 文案动词方向 | 画面动作 | 检查 |
|---|---|---|
| 伸 / 探 | 身体向前伸出、脖子或手臂伸长 | 遮住字幕，观众能说出“它在伸”吗？ |
| 缩 / 躲 | 身体缩回、退后、藏进壳或阴影 | 同上 |
| 盯 / 粘 | 视线或身体粘住一个物件不放 | 同上 |
| 回 / 放 | 画面倒回去一次，或同一动作重复 | 同上 |
| 涨 / 升 | 仪表指针上升、格子逐格点亮 | 指针真的动了吗？还是只换了数字？ |
| 定 / 停 | 化身停住、终卡定格 | 定格够久吗？手机缩略图下还认得出吗？ |

### 7.3 身体出现次数

- 每个情绪的身体在全片至少出现两次：化身段出现一次，信息卡段再出现一次。
- B 型多卡：每个情绪的身体只属于那张卡，不要让上一张卡的身体跑到下一张卡里串场，
除非是终卡有意回场，且回场时要让观众认得出“这是开头的那个身体”。

## 8. 讲解设计：情绪也要演出来

- 每个情绪必须先定一个“身体”（见第 7 节），再写句子。画不出来的句子改句子，不硬配抽象动画。
- 身体的动作必须就是文案里的动词。文案写“伸”，画面就要真的伸；
文案写“粘”，画面就要真的粘住不放；文案写“回放”，画面就要真的倒回去一次。
动作和文案对不上，就改文案或改动作，不要硬贴。
- 仪表不是装饰：触发段仪表必须真的在动（指针上升、格子点亮、颜色加深），
命名段仪表定格在触发的结果上，观众才能把“情绪强度”看成一个数。
- 约五分之一的句子不配新画面：提问句、命名句、结论句、收束句可以停住上一幕或只上字，
不要为了填满时间给结论再画一张新图。
- 一个比喻或一个身体用到底：同一集里不要中途换身体、换仪表、换主题色含义。

## 9. 信息卡字段：照表填空

### 9.1 A 型单集卡（左卡右图）

```
顶部：系列名 · 其第几
大字：情绪单字或双字名（全片最大字号之一）
定义：一句话，说清这个情绪是什么，不超过 20 字
症状行 1：动词 + 一句具体表现（动词必须能在画面里演出来）
症状行 2：动词 + 一句具体表现（同上）
解法行：动词 + 一句可执行的做法 + 古籍或出处（出处可空，空则不写出处行）
右侧：本集化身（动物或剪影），主题色描边
底部：收束句（反转或重新解读，只写一句，停留最久）
```

### 9.2 B 型多卡（每卡同版式，只换内容）

```
顶部：系列名 · 其第几
大字：情绪名
拉丁或英文名：与大字并列，斜体小字
定义：一句话，不超过 20 字
象征：一个动物或物件 + 它的名字（双语小字）
化解：一个做法或对立项（双语小字）
底部阐释：一句小字，解释象征或化解为什么成立
右侧：本卡剪影，单色霓虹描边
```

### 9.3 西式命名变体卡（可选，只在西式命名系列里用）

```
大字：情绪名
拉丁或英文名：与大字并列
司掌者：一个名字（必须核实来源，拿不准就不用这一行）
刑罚或后果：一句，不写血腥细节
对立美德：一个词 + 英文或拉丁名
```

三种卡式一集只用一种，不要在一集里混用 A 型解法行和 B 型象征行。

### 9.4 字段检查表（交卡前逐项打勾）

- [] 大字是不是本集唯一最大字号之一？
- [] 定义是不是一句话，且不超过 20 字？
- [] 每个动词是不是都能在画面里演出来？
- [] 解法是不是可执行的动作，而不是一句劝告？
- [] 出处、象征、化解、拉丁名是不是都在事实表里？
- [] 右侧身体是不是本集的身体，而不是上一集串场的身体？

## 10. 字幕稿规则（短片版）

默认世界的字幕规则照用，量要按短片重算：

- 每句中文主句不超过 20 字，一句一个屏上动作。
- A 型 15 秒版：旁白或屏上字幕 5–7 句为宜，预留命名卡和收束卡的无字幕定格时间。
- B 型 50 秒版：每张卡 2–3 句，引言句 + 定义句 + 阐释句，不要在一张卡里写一段散文。
- 每句必须含一个新信息：新事实、新数字、新转折、新动作，四者有其一。
- 禁用清单照用：不写“今天我们来聊聊”“这告诉我们”“众所周知”等口播腔。
- 数字纪律照用：屏上每个数字先算或先查证，模拟标“模拟”，示意标“示意”，
情绪片没有模拟时，就不要硬造百分比和人数。
- 事实表：每集一张，列出情绪名来源、象征来源、化解或出处来源、拉丁或英文名来源，
每一项写“已核实 / 待核实”，待核实的不进成片。

## 11. 分镜表与时间轴

### 11.1 A 型分镜表（15 秒骨架）

```
| 时间 | 屏上文字（只写字段，不抄成片） | 呈现动作 | 屏上是什么，在干什么 | 屏上小字 | 观众明白了什么 | 声音 |
| 0–5s | 触发句（日常小事） | 照句子演 | 具体场景 + 仪表指针上升 | 场景标签 | 我也遇到过这件事 | 触发段织体 |
| 5–8s | 化身名或系列标签 | 照句子演 | 化身入场，动作 = 下一拍动词 | 其第几 | 这个情绪长这样 | 转场对齐节拍 |
| 8–13s | 信息卡（按第 9 节字段填） | 停住亮字 | 左卡右图，卡片逐行亮起 | 定义/象征/化解/出处 | 这个情绪叫什么，有什么表现，怎么解 | 命名段织体 |
| 13–15s | 收束句 | 停住亮字 | 终卡定格，不再切新画面 | 无新增小字 | 原来还可以这样看 | 收束回落 |
```

### 11.2 B 型分镜表（50 秒骨架）

```
| 时间 | 卡 | 引言句 | 卡片字段 | 剪影动作 | 颜色变化 | 观众明白了什么 |
| 0–10s | 其一 | 具体场景一句 | 按 9.2 节填 | 剪影入场 + 主题色描边 | 主题色 1 | 第一种情绪叫什么 |
| 10–20s | 其二 | 具体场景一句 | 按 9.2 节填 | 同版式，只换剪影 | 主题色 2 | 第二种情绪叫什么 |
| … | … | … | … | … | … | … |
| 35–50s | 终卡 | 无新引言 | 最核心一情绪大卡 | 终卡定格 | 终卡主题色 | 整组里最核心的是哪一个 |
```

分镜表写完自查：遮住字幕列只读“屏上是什么，在干什么”仍能看懂，才算写完；
“停住 / 亮字”类占比接近五分之一；核心身体在全片至少出现两次。

## 13. 选题种子与原创示例

### 13.1 只给方向，不给现成文案

- 公共情绪组：按一组公共概念成集，例如一组五项、一组七项，每集一个名字，合集内版式统一。
- 日常触发组：从排队、消息、找东西、被比较、被拒绝这类小事出发，反推它背后是哪种情绪。
- 对照组：同一情绪给两个对照卡，例如“对别人时”和“轮到自己时”，只留一处不同，观众一眼看出区别。
- 避开：只讲道理没有触发的题、没有身体（动物、剪影、仪表）的题、需要编造数据才能成立的题。

### 13.2 原创示例骨架（示例是新编的，不是任何成片的复述）

**示例 1：A 型 · 拖延（仅作骨架演示，文案需按第 10 节重写）**

- 触发：截止时间临近，桌面上还摊着没动的第一页。
- 仪表：倒计时格子逐格变暗，指针或进度条向截止线移动。
- 化身：一个总在原地打转的小身体，动作就是“转圈、停下、再转圈”。
- 卡片：大字 + 定义 + 两条可演的症状动词 + 一条可执行的做法。
- 收束：把“拖延”重新解读为一个可拆解的动作，而不是一句对自己的评判。

**示例 2：B 型 · 一组日常情绪（仅作骨架演示）**

- 其一：紧张 —— 触发是上台前的心跳感，身体是紧绷的剪影，主题色 1。
- 其二：尴尬 —— 触发是说错话后的停顿，身体是缩小的剪影，主题色 2。
- 其三：释然 —— 触发是说出口之后松一口气，身体是舒展的剪影，主题色 3。
- 终卡：选本组最核心的一个情绪做大卡，点明它在整组里的位置。

> 示例里的触发和身体都是新编的骨架，正式开工时要按第 12 节简报重新填，
> 并把每一项来源写进事实表。

## 14. 代码实现与渲染

- 从 `assets/template.html` 起改，不要从零造轮子。
- 页面必须暴露 `window.render(t)`，画面只由时间决定，随机数固定种子，禁止计时器和帧间状态。
- 五区布局照用，但 A 型要做两处收紧：
- 字幕带仍是唯一放字幕的地方，动物、卡片、仪表一律不许伸进字幕带；
- 终卡定格时，字幕带只留收束句，不再叠加新注释。
- 一集一站一个函数：触发、化身、信息卡、收束各一个函数，自己管自己的进出场包络；
常驻元素（水印、系列标签、读数、字幕）在最外层统一画，永远最后画字幕。
- 建议的最小函数骨架（伪代码，不是成片代码）：

```
render(t):
drawBackground(t) # 深蓝黑底 + 极淡星点
drawTrigger(t) # A1：场景 + 仪表上升
drawBody(t) # A2：化身入场，动作 = 文案动词
drawEmotionCard(t) # A3：左卡右图，逐行亮起
drawClosingCard(t) # A4：终卡定格
drawOverlay(t) # 水印 / 系列标签 / 字幕（最后画）
```

- 渲染与合成命令照用 `SKILL.md` 第 6 步，15 秒版把 `--duration` 改成实际时长，
不要为了凑 130 秒而注水。
- 密度体检：`scripts/check_density.py` 的默认阈值是按长片定的，
短片先用它查超长句和口播腔，字数和句速结论要按本集实际时长人工复核，不许只看通过与否。
- 预览先行：页面能跑的第一时间起本地预览，边写边让用户看到，
先跑通 3 张关键静帧（触发、命名卡、终卡），确认后再做全片。

## 15. 质量门与常见错误

### 15.1 质量门（短片版，机器过检不等于可以交片）

- 看图流程照用：`--sheet` 看全局，`--stills` 看细节，`--motion` 看转场，至少修两轮。
- 短片专项检查：
- [] 触发句是不是具体小事，而不是抽象议论？
- [] 化身动作和卡片动词是不是同一个动词？
- [] 一屏是不是只有一个主体在动，其余降到三成亮度或离场？
- [] 主题色是不是全片一个意思，有没有中途换义？
- [] 终卡是不是定格够久，手机缩略图下大字仍可辨认？
- [] 每一项事实（情绪名、象征、化解、出处、拉丁名）是不是都在事实表里？
- [] 弹幕、平台水印、登录弹窗是不是只属于平台层，不属于成片设计？成片自检时要关掉弹幕再看一遍。
- 终检三遍照用：静音遮字幕看一遍、只读字幕看一遍、对照门槛表逐条过。
- 交片附诚实清单：哪些段落没逐帧看过、哪些声音未实听确认、哪些事实待核实。

### 15.2 常见错误对照表

| 症状 | 原因 | 怎么修 |
|---|---|---|
| 触发像说教，观众代入不了 | 触发写成了道理 | 换成一个具体场景 + 一个可数的小事 |
| 动物很好看，但和文案无关 | 先画了动物，后配了文案 | 回到第 8 节：动作必须就是文案动词，否则改文案或改动作 |
| 一张卡塞了两个情绪 | 想讲得太多 | 拆成两张卡，或删掉次要的那个 |
| 颜色越用越多 | 每行都想强调 | 回到第 6 节：主题色一个，辅助色最多一个 |
| 终卡一闪而过 | 收束段没留定格 | 终卡至少定格 3 秒，字幕带只留收束句 |
| 仪表不动 | 仪表只是装饰图 | 让指针、格子或颜色真的动起来，否则删掉仪表 |
| 字幕带被卡片压住 | 元素最低点超了 80% 纵向 | 把元素上移，字幕带（约 82%–95%）保持干净 |
| 换卡像换了一条片 | 版式、底色、字体一起换了 | 同版式换内容，只换主题色、剪影、步骤标签中的一项或几项 |
| 拉丁名或出处写错 | 没查证就写了 | 回事实表核实，拿不准就删掉这一行 |
| 声音和画面各走各的 | 织体没对齐章节 | 命名卡落在小节线上，收束段回落；未实听的一律写未确认 |
